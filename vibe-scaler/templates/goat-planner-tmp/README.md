# goat-planner-tmp

Staging area for an **oversized idea** before it becomes multiple Vibe Scaler programs.

## When

Use **`/vs-planner`** when a single program would need **more than 15 executable chunks** (or the ideator judges the ask too large for one `NN_<short>/` folder).

## Files

| File | Role |
|------|------|
| `original-big-idea.md` | Full vision (verbatim + links) |
| `split-index.md` | Table: child program `NN_<short>`, chunk budget, dependency order |

## Exit

For each row in `split-index.md`, run **`/vs-ideator`** with that slice only. Delete or archive `goat-planner-tmp/` after all children are created (or keep `original-big-idea.md` linked from playground root index).
