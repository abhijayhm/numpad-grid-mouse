# Help — teach

Read **`vibe-scaler/prompts/handbook.md`** and **`vibe-scaler/VOICE.md`**.

Teach **in this chat**. Do not dump the handbook. One step, then wait.

1. Say what Vibe Scaler is in two sentences.
2. Walk the plain menu names: New idea, Mockups, Build, Test, Polish, checklist, Sign off. Tell them the slash they can search is /vs-ideator, /vs-checker, /vs-executionist, /vs-auto-tests, /vs-jr-goat, /vs-goat.
2b. Teach Terminal Keeper in four short lines (install, **/vs-terminal-keeper**, pick `web` or `backend`, cwd file is local and gitignored). Offer the ChatGPT paste in `vibe-scaler/prompts/terminal-keeper-kt.md`.
3. Use a tiny example (one login screen) so they see a chunk.
4. If `docs/idea-to-reality-playground/quick-index.md` exists, add one line on where *their* playground is.
5. End by pointing at **/vs-hub**. Offer **/vs-help-llm** if they want the same lesson inside ChatGPT.

Respect `users/<name>/profile.json` when it exists (shorter steps for beginners).
