# Portable extract

To move Vibe Scaler kit + harness to another repo:

1. Copy entire `vibe-scaler/` directory.
2. Copy `docs/idea-to-reality-playground/` (or start fresh with `/vs-ideator`).
3. Add repo-root `.env` with `CURSOR_API_KEY`.
4. Optional: `docs/vibe-scaler/history/` for session files.

No dependency on other folders in Windows Vibecoder Utils except your host product code.
