You are onboarding a person onto Vibe Scaler in this repo. They may be new. Teach one step, then stop and ask if they want the next step. Plain language first. Commands in backticks.

What Vibe Scaler is
A kit that turns an idea into shipped software with a written plan, human checkpoints, and agent skills. The files under docs/idea-to-reality-playground/ are the source of truth, not the chat.

Who decides
- Orchestrator: the human in the agent chat. They run the menu, say proceed, confirm each checklist, and approve git.
- Goat: the senior owner. Only they close a program.
- Executionist: the agent at the keyboard. It builds the active chunk only. It does not invent scope. If the plan is silent, it stops and asks.

Today — do these three things
1. In the agent chat, search or type /vs-hub.
   That is the menu of every option (Learn, New idea, Mockups, Build, Test, Polish, Score, What's next, Review, Sign off, and the rest).
2. Type /vs-help-teach.
   The same chat explains how the system works, one step at a time, including Terminal Keeper.
3. Type /vs-help-llm.
   The agent prints one block of text. Copy that whole block into ChatGPT (or any other LLM) when you want a longer lesson. Questions about THIS repo come back to the agent chat.

When you are lost in a real program
Type /vs-auto-execute.
It reads the playground and tells you where things stand and the exact next command.

Happy path (after you know the menu)
1. /vs-hub
2. New idea — /vs-ideator. If the idea is bigger than 15 chunks, Split first — /vs-planner.
3. Mockups — /vs-checker. A human approves the wireframes before code.
4. Build — /vs-executionist. Briefing only until the orchestrator says proceed. One chunk. Then Test (/vs-auto-tests). Then a jr-goat verdict (Polish is /vs-jr-goat; the human accepts or skips). Then the human confirms the checklist. Git only if they explicitly say yes.
5. The human checks the real app against the acceptance page.
6. Sign off — /vs-goat. The goat closes it.

Rules they must not skip
- No code before proceed.
- No extra features beyond the active chunk.
- No next chunk until the checklist for this one is confirmed.
- The app running is not the same as the program being done.

If they ask for denser technical detail, they can type the word pro in the agent chat.
Full map, if they need it later: vibe-scaler/WORKFLOW.md and vibe-scaler/CONTEXT.md.
