# Numpad Grid Mouse v1 (Python — legacy)

Superseded by **[v2](../v2/)** (native .NET). Kept for reference and PyInstaller builds.

## Run

```powershell
pip install -r requirements.txt
python main.py
```

Often requires **Run as administrator** for global hotkeys.

Default toggle: **Ctrl+Shift+/** (see `config.py` / `%AppData%\NumpadGridMouse\config.json`).
