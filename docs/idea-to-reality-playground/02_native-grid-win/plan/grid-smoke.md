# 2-minute smoke test

1. Launch `v2\artifacts\NumpadGridMouse.exe` — tray icon appears.
2. **Ctrl+Shift+G** — blue grid on active monitor; press **5** twice; **Enter** — click lands.
3. **Esc** — grid hides.
4. **Ctrl+Shift+A** — green dot bottom-left; arrows move cursor; **Enter**×2 double-clicks.
5. **Esc** — dot gone.
6. Tray → enable **Run at Windows logon**; confirm registry value `NumpadGridMouse`.
