# Python vs native parity

| Feature | Python | Native (.NET) |
|---------|--------|----------------|
| Grid toggle | `Ctrl+Shift+/` (config) | `Ctrl+Shift+G` |
| Arrow mode | — | `Ctrl+Shift+A` + HUD dot |
| Grid 3×3 / numpad map | Yes | Yes |
| Drill on repeat toggle | Yes | Yes (`toggle_drill_center`) |
| Right click in grid | Shift+Enter | Shift+Enter |
| Scroll arrows | Yes (scaled) | Yes |
| Sounds | Yes | Not in v1 |
| Multi-monitor picker | Numbered picker | Monitor under cursor |
| Admin for hotkeys | Often yes | No |
| Run at logon | Manual | Tray checkbox → HKCU Run |
