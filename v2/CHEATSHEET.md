# Win + Shift moat

## Global (anytime)

| Keys | Action |
|------|--------|
| **Win + /** | Grid on / off |
| **Win + Shift + ?** | Help overlay |
| **Win + Enter** | **Left click** at current mouse position |
| **Win + Enter** twice (quick) | **Double-click** at pointer |
| **Win + Alt** | **Right click** at current mouse position |

## Grid — aim (no Win)

| Keys | Action |
|------|--------|
| **1–9** | Zoom cell + move pointer there |
| **Backspace** | Up one level (pointer follows) |
| **Esc** | Close grid only |

Grid stays open after **Win+Enter** / **Win+Alt** so you can aim again. Use **Esc** or **Win+/** to leave.

## Grid — extras (**Win + Shift +** …)

| Keys | Action |
|------|--------|
| **↑** **↓** | Scroll (vertical) at pointer |
| **;** | Toggle left drag |
| **'** | Right-drag path |
