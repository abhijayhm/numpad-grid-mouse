# Numpad Grid Mouse (Windows)

Native .NET 8 WPF tray application.

## Run

```powershell
dotnet run --project src/NumpadGridMouse.Win/NumpadGridMouse.Win.csproj
# (from v2/ directory)
```

## Build

```powershell
dotnet build src/NumpadGridMouse.Win/NumpadGridMouse.Win.csproj -c Release
```

## Config

`%AppData%\NumpadGridMouse\config.json`

## Hotkeys (batch A)

- **Ctrl+Shift+G** — grid (stub until overlay chunk)
- **Ctrl+Shift+A** — arrow mode (stub)
